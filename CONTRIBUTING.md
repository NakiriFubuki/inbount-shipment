## 🛠️ How to Contribute

1. **Fork the repository** 🍴
2. **Clone your fork**
   ```bash
   git clone https://github.com/YOUR_USERNAME/inbount-shipment.git
   cd inbount-shipment
   ```
3. **Create a new branch** 🌱
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Set up locally**
   - Place the project under XAMPP `htdocs`
   - Start Apache + MySQL
   - Run `composer install`
   - Use `install.php` or import `database/schema.sql`
5. **Make your changes** ✨
6. **Commit your changes** 💾
   ```bash
   git commit -m "Add: a meaningful commit message"
   ```
7. **Push to your branch** 🚀
   ```bash
   git push origin feature/your-feature-name
   ```
8. **Open a Pull Request** 🔃

## 🧭 Contribution Guidelines

- Keep the **PHP / MySQL / HTML / CSS / JS** stack  
- Match existing naming, indentation, and UI style  
- Use **prepared statements** for SQL and escape output for XSS safety  
- Prefer clear, small commits with meaningful messages  
- Update README screenshots if you change major UI flows  

---

## ✅ Pull Request Process

- Base your PR on `main` (or the default branch)  
- Describe what changed and why  
- Link related issues when applicable  
- Wait for review before merging  

---

## 🐛 Reporting Issues

Found a bug or have a feature idea? Open an **Issue** with:
- Steps to reproduce  
- Expected vs actual behavior  
- Screenshots if UI-related  
- PHP / MySQL / browser versions if relevant
